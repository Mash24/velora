# Velora Medical Supplies

B2C medical-supplies shop with a back office for products, stock, customers, orders, payments and deliveries.

## Scripts

- `npm run dev` — local shop + admin
- `npm run db:push` — apply schema to Supabase
- `npm run db:seed` — sample catalogue (gloves, masks, stethoscope, crutches)

## Admin

Sign in at `/admin/login` using `ADMIN_EMAIL` and `ADMIN_PASSWORD` from `.env.local`.
